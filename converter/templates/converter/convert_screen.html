Understanding the Scores

Match table (Show Matches) — each row is a candidate term:

score — how closely the term matches the column header, as returned by the Linked Open Vocabularies service. Higher means a more relevant term. The Best Match is the one chosen for that column.

Vocabulary Scores (Show Scores) — ranks whole vocabularies:

Average Match Score — the average term score across all of this vocabulary's matches. Reflects how well the vocabulary's terms fit your columns.

Nr of Produced Matches — how many of your columns this vocabulary has a match for (its coverage).

Combi Score — the combiSQORE ranking: it combines the average match score with coverage, normalised to 0–1, so a vocabulary that fits many columns well ranks highest. This drives the automatic best-match selection.

How Smart Cow Works

Smart Cow turns a CSV file into linked-data triples. It suggests vocabularies for each column, lets you fine-tune the metadata, and exports the result as N-Quads. Here is what each part does:

1. Load Dataset

Start by uploading a CSV on the welcome screen (or Load Dataset in the menu). Smart Cow detects the delimiter, reads the column headers, and queries the Linked Open Vocabularies (LOV) service for matching vocabularies. This can take a moment while it contacts LOV.

2. CSV Preview (left panel)

Shows the first rows of your file so you can confirm it was parsed correctly. Use Load Full Dataset to view every row in a popup.

3. Vocabulary Recommender (middle panel)

Request type — Homogenous tries to find one vocabulary that fits all columns; Single picks the best match for each column independently.

Replace All — fills the metadata with the recommended best match for every column at once.

Header cards & Search — each card is a column. Click Show Matches (or search a header name) to open the match window. Vocabulary Scores shows how each vocabulary was ranked.

4. Match window

Lists the Best Match and All Matches for a column. Click a row to Insert it into the metadata, or open its Source URI. The window can be resized from its top edge.

5. Metadata editor (right panel)

Toggle between Editor and Raw JSON. The Editor groups everything into blocks: General (base URL, language), Dataset (title, publisher, license), Table Schema (primary key, about URL), Namespaces, and Columns. Edits sync to the Raw JSON when you switch views or save.

6. Vocabulary Manager

Define a preferred order of vocabularies. On Submit, Smart Cow re-selects each column's best match, preferring your prioritised vocabularies (falling back to the ranking when there is no match). No new requests are made.

7. Save & Export

Save writes your metadata edits to disk. Convert (or Export Data) generates the N-Quads, and a download link appears in the notification. Always Save before Convert so your edits are included.
